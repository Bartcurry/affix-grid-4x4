# 4×4 词条法阵

在 4×4 棋盘摆放、升级并连锁触发符文。从 26 种符文里搭建连锁、剧毒、金币或增幅阵容。打过 20 波可继续无尽模式。

## 在线试玩

[GitHub Pages 试玩](https://bartcurry.github.io/affix-grid-4x4/)（首次部署成功后可用）。仓库管理员须在 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**。合并到 `main` 或从 `main` 手动运行 **Test and deploy to GitHub Pages**；部署后的真实网址在工作流 `deploy` 任务中显示。PR 只测试和构建，不发布。

## 本地运行

需要 Node.js 20.19+（20.x）或 22.12+ 的当前受支持偶数版本。

```sh
npm ci
npm run dev
npm test
npm run build
npm run preview
```

## 如何玩

- 新局可选借火、养苔、攒钱、落印。可直接「开局并打首波」、先布阵，或从同一屏进入每日残局和三阵接力。点首波推演的符文可查看它的作用。打过首波后，棋盘上方的提示可以直接试摆第 2 波专属补货。换开局会先确认。
- 开局可选「入门」或「标准」。入门战役每波多一次免费刷新，过关补一层护盾（最多三层）。两种难度各自记录最高成绩，同局邀请保留原难度。无尽模式使用统一规则。
- 「新手练习」有镜子连锁、矿脉重炮、叠毒引爆三课。可以随时退出，练习进度不会写入战役。
- 棋盘上方的「分享」可生成同局链接。朋友点开就能用同种子、同开局打一局，先比通关波数，再比最高连击。同局挑战单独存档，打完可发回战绩。此前版本的邀请链接会提示失效。
- 布阵时可用「分享 → 接手这一波」发送当前阵容。朋友可以换位、试打、对比伤害和连击，再发回改阵链接。战斗条件和持有符文仍一致时，可把改阵应用到主线，并用撤销恢复。
- 「每日」每天北京时间零点换题。点两枚符文换位再试打，保留流派羁绊并关闭暴击。从 2026 年 11 月 21 日起，14 个题型轮换，每轮调整原阵。解开后分开记录最少步数和最高伤害，并可切换对应提示。可补玩近七期，新题的分享链接会带上自己的成绩。
- 「每日 → 三阵接力」每周一换题。三阵共用换位步数，试打过关后可锁定本阵成绩，也可以再花一步争取更高的总伤害。最佳成绩存在本机，可复制挑战链接和朋友玩同一组题。
- 每日残局或三阵接力出成绩后，点「战绩卡」可保存带原题二维码的图片、复制挑战链接，或用浏览器的系统分享。

- 点击符文可查看作用范围，再点「看词条」查看说明或回收。拖动可交换法阵、备战区的位置，也可点选符文后点目标格来换位。键盘可用方向键、回车和 `Delete` 操作棋盘。
- 「图鉴 → 阵型练习」提供六套可以动手换位的原阵。对照换位前后的格子和实算伤害，练习符文的朝向、出手顺序和增幅条件。
- 购买后先放入四格备战区；同名同星的三个符文自动合成，优先保留法阵上的位置。商店会在买入可升星时提前提示。每波开始自动刷新未锁商品，另有一次免费手动刷新。
- 商店的「试买」可以比较三张现货。点棋盘格看花钱和换位后的实际伤害，也可以只买入。确认「购买并落位」后，购买和摆位可一起撤销。
- 商店的「升星簿」一起清点棋盘和备战区的同名符文。盯住一枚后，刷到现货会高亮。买一枚就能升星时，可以预先查看保留格、腾出的格和推演伤害，再确认购买。
- 第 2 波商店会给当前开局补一枚搭配符文（占用首个未锁位置）。手动刷新时可指定优先流派：首个未锁位置尽量找同稀有度的对应符文，其他位置仍随机。锁住的商品不会换掉。
- 法阵按从左到右、从上到下激活，连锁立即插入。折射镜触发右边，落铃触发正下方。只在首波，保留开局两枚符文的位置，会额外打出 42 点伤害。
- 从第 4 波起会遇到不同敌人：铁壳卫的前两次受击减伤，漏毒翁怕回合末的毒，石狮的中间两列更好打，回音钟怕连锁，闭门王兼有护甲与连锁弱点。无尽模式轮换这五种敌人。
- 新战役第 20 波的闭门王在三层护甲打破后会锁定上一击所在的列，同列下一击直伤减少 30%。换列、回合末毒伤和共鸣毒爆可以绕过。终战复盘会标出轮锁减伤，通关后可分享原阵供朋友试打。
- 点击顶栏「敌情」打开对阵表，查看各波敌人的生命、招式和布阵提示。可以带当前阵容、金币和遗物试打未来的波次。未来波次的试阵不会改变战役进度。
- 新开的战役在第 5、10、15 波可查看「悬赏路线」。可以走原路，也可以改打另一名敌人换取额外金币、刷新、修盾或刻印。开战前可以试算和换路。旧存档和旧版同局链接仍按原路线结算。
- 新战役第 11 波开战前可在「转铸台」免费换一枚同稀有度符文，保留星级和永久威力。「找转铸方案」还会试算转铸后再换位一次的效果。确认前可比较伤害、共鸣与自动升星结果，转铸和换位可以一起撤销。
- 新战役通关后，第 21 波和从第 25 波起的每个天劫区段开战前会停靠营地。可以拿 18 金和两次免费刷新、修复一层护盾，或把离火位挪到另一个格子。营地会实算各选项的下一战伤害；同一波有遗物时先选遗物。对阵表能查看下次换天劫的波次。
- 打过第 4、8、12、16 波后，每次三选一拿遗物。领取前可以用当前阵容比较下一波的伤害、结算金币和额外刷新。新局的四个节点现在会出现青玉算盘、化功散等扩展遗物，已有对局和旧版同局链接沿用各自的遗物表。
- 「战斗推演」用实际结算规则计算伤害、连击、战斗金币变化和过关奖励（含利息）。拖到新格子或用键盘选中后移动光标，可以先看换位差值。箭头显示触发方向，虚线表示其他作用范围。格号和阵眼名称会一直显示。
- 推演栏的「试阵」可以在副本里换位。伤害不足时，点「找打法」会试遍单步换位，再从较强的摆法里继续试两步。确认应用后才会改变主线阵容，可以用一次撤销恢复。
- 战后点「复盘」，可用 1× 或 2× 回放原阵，也可以逐步查看连锁、敌人生命、毒层和金币。快捷按钮能跳到最大一击、首次轮锁或回合结算。失败结算里也能打开，再用「试这波原阵」换位试打。
- 战斗时可以看扫描格和触发进度。长连锁会合并部分演出，最大一击和击破仍会突出显示。倍速按钮可在 1×、2× 和立即结算间切换；系统设为减少动态效果时会直接结算，完整战斗记录仍可复盘。
- 未击破 Boss 时，先从失败面板对比保盾和扣盾后的重打推演。可以直接试改阵、保存换位，再选重试方式。敌人恢复满血、剧毒清零，已经获得的金币保留。保盾广告为 1 秒本地模拟。
- 进度保存在浏览器本地。通关或战败后可预览并保存战绩卡，朋友扫图上的二维码就能用同样的开局打同局挑战。

`src/core/` 是不依赖 DOM 的确定性战斗和经济逻辑；`src/sim/balance.test.ts` 覆盖连锁护栏、毒层、金币、升星等规则。Canvas 和 Web Audio 负责回放，不参与计算。
