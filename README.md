# 4×4 词条法阵

在 4×4 棋盘摆放、升级并连锁触发符文。从 26 种符文里搭建连锁、剧毒、金币或增幅阵容。打过 20 波可继续无尽模式。

## 在线试玩

[在线试玩](https://bartcurry.github.io/affix-grid-4x4/) · [今日残局](https://bartcurry.github.io/affix-grid-4x4/daily.html) · [TapTap 上架素材](./taptap/)

## 本地运行

本地构建和 GitHub Actions 使用 Node.js 24 LTS。

```sh
npm ci
npm run dev
npm test
npm run build
npm run preview
```

`npm run build` 生成 `dist/`。推送到 `main` 后，GitHub Actions 会重新构建并部署这份产物。

## 如何玩

- 初次打开游戏会看到可以跳过的入门指引。启动页可实算演示镜子换位前后的连锁，下面有战役、短局挑战和阵型练习。已有战役存档会直接续玩。战役中可以通过顶栏「模式」回到启动页，或从棋盘上方「短局」打开每日残局和三阵接力。
- 新局可选借火、养苔、攒钱、落印。可直接打首波或先布阵。点首波推演的符文可查看它的作用。首胜后，阵容伤害不足时可以用「试阵备战」试买、摆放符文，比较不同位置的第 2 波伤害。确认应用才花金币，买入和换位可以一起撤销。换开局会先确认。
- 首次开局默认选中「入门」，也可切到「标准」或「进阶」。入门战役每波多一次免费刷新，过关补一层护盾（最多三层）。进阶从两层护盾开局，第 2–20 波敌人生命提高 20%。三档难度各自记录最高成绩，同局邀请保留原难度。无尽模式使用统一规则。
- 「阵型练习」中的「新手教学」有镜子连锁、矿脉重炮、叠毒引爆三课。跟着高亮格换位，再试打比较伤害。战役开局设置里的「先练换位」可以练完直接开战。
- 启动页「入门指引」和战役顶栏「指引」都能查看首战、换位、第二波备战和每日残局的操作。指引内可以随时重练三课，练习完成后返回指引。
- 「阵型练习」中的「阵师试炼」有五道常驻题，从镜子朝向、攒钱开炮练到磨护甲、叠毒和轮锁。各关可随时重练，提示只亮一个换位起点。最少步成绩保存在本机，试打后可看逐步战况。
- 「设置 → 棋盘外观」可以预览实际棋盘，并选用已解锁的配色。阵师试炼五关全过可选青玉，每日同题双满可选寒玉，任意难度战役过第 20 波可选赤铜。外观在这个浏览器里跨新局保存。
- 棋盘上方的「分享」可生成同局链接。朋友点开就能用同种子、同开局打一局，先比通关波数，再比最高连击。同局挑战单独存档，打完可发回战绩。此前版本的邀请链接会提示失效。
- 布阵时可用「分享 → 接手这一波」发送当前阵容。朋友可以换位、试打、对比伤害和连击，再发回改阵链接。战斗条件和持有符文仍一致时，可把改阵应用到主线，并用撤销恢复。
- 试阵时，用 1–4 步换位打出比原阵更高的伤害后，可点「发阵型挑战」。朋友从原阵开始，在相同或更少步数内打到目标伤害就能回传成绩。阵型挑战在独立的试阵页进行。
- 「每日」每天北京时间零点换题。点两枚符文换位再试打，保留流派羁绊并关闭暴击。从 2026 年 11 月 22 日起，18 个题型轮换，每轮调整原阵。「破甲换列」「借邻蓄力」「隔行送火」「四角磨阵」各用一种不同的站位规则。最少步数和最高伤害分开记，两个目标拿满后可直接补做近七期。按朋友的链接进入同一期，可以比较双方步数和最高伤害。
- [今日残局](https://bartcurry.github.io/affix-grid-4x4/daily.html)每次打开都进入当天的题。复制的挑战链接则保留题目日期和可比较的成绩。
- 每日残局和阵师试炼会把已完成的换位保存在当前浏览器，刷新后可继续或撤销。近七期会标记尚未解开的草稿，阵师试炼优先打开最近摆过的未通关关卡。
- 每日残局标题旁的「题册」可以按月翻阅所有已发布的题，筛出待解、待双满和有草稿的题。选中日期可看题名和本机成绩，再打开原题或继续上次的摆法。
- 每日残局试打后能点「看出手」，沿棋盘上的箭头逐步看连锁、减伤、金币和毒层，也能跳到最大一击。通关后可直接复制成绩和原题链接，或生成战绩卡。
- 支持成绩对比的每日题里，新打出的最少步成绩在 12 步以内时，分享链接和战绩卡二维码会附上换位记录。好友自己解开同一道题后，可以逐步查看通过试算核对的摆法。已有的挑战链接仍可使用。
- 「短局挑战 → 三阵接力」每周一换题。三阵共用换位步数，试打过关后可预览锁定这阵会怎样影响三阵总伤害上限，再决定锁定或重摆。最佳成绩存在本机，先比总伤害，同伤害比用步。打开朋友的挑战链接可比较成绩，通过后可用「回传战绩」把同一期的战绩卡发回去。
- 每日残局或三阵接力出成绩后，点「战绩卡」可保存带原题二维码的图片、复制挑战链接，或用浏览器的系统分享。

- 点击符文可查看作用范围，再点「看词条」查看说明或回收。拖动可交换法阵、备战区的位置，也可点选符文后点目标格来换位。键盘可用方向键、回车和 `Delete` 操作棋盘。
- 「图鉴 → 阵型练习」提供六套可以动手换位的原阵。对照换位前后的格子和实算伤害，练习符文的朝向、出手顺序和增幅条件。
- 「图鉴 → 战绩」可试打已记录的末战，用当时的符文、敌人和资源换位推演。同种子、同开局和同规则下保留打得最远的战绩，同波数比最高连击。点「同种子重开」会先确认。
- 购买后先放入四格备战区；同名同星的三个符文自动合成，优先保留法阵上的位置。商店会在买入可升星时提前提示。每波开始自动刷新未锁商品，另有一次免费手动刷新。
- 商店的「试买」同时列出三张现货能打的最高伤害。当前伤害不足时，会优先展示买入成本最低的过关解。点棋盘格可比较落位、伤害和结算金币。「试阵 → 带这个阵试买」可以把未应用的阵型一起算进去，确认后改阵、购买和落位只需撤销一次。
- 商店的「升星簿」一起清点棋盘和备战区的同名符文。盯住一枚后，刷到现货会高亮。买一枚就能升星时，可以预先查看保留格、腾出的格和推演伤害，再确认购买。
- 第 2 波商店会给当前开局补一枚搭配符文（占用首个未锁位置）。手动刷新时可指定优先流派：首个未锁位置尽量找同稀有度的对应符文，其他位置仍随机。锁住的商品不会换掉。
- 法阵按从左到右、从上到下激活，连锁立即插入。折射镜触发右边，落铃触发正下方。新开的「借火」首波，镜子对着右边的电火花，首波敌人有 40 生命。已有存档和旧同局链接沿用各自的首波规则。
- 开战后，棋盘上方会显示正在出手的符文、连锁方向、伤害和击破的那一击。可以切换倍速或立即结算，战后可在「复盘」逐步查看完整记录。
- 从第 4 波起会遇到不同敌人：铁壳卫的前两次受击减伤，漏毒翁怕回合末的毒，石狮的中间两列更好打，回音钟怕连锁，闭门王兼有护甲与连锁弱点。无尽模式轮换这五种敌人。
- 新战役第 20 波的闭门王在三层护甲打破后会锁定上一击所在的列，同列下一击直伤减少 30%。血条下会显示剩余护甲或轮锁列，战斗中棋盘也会框出被封的列。换列、回合末毒伤和共鸣毒爆可以绕过。终战复盘会标出轮锁减伤，通关后可分享原阵供朋友试打。
- 点击顶栏「敌情」打开对阵表，查看各波敌人的生命、招式和布阵提示。可以带当前阵容、金币和遗物试打未来的波次。未来波次的试阵不会改变战役进度。
- 战役在第 5、10、15 波可查看「悬赏路线」。可以走原路，也可以改打另一名敌人换取额外金币、刷新、修盾或刻印。路线卡会显示本轮的伤害和结算后金币。选中路线后可先试阵，伤害不足时还可以找一两步内的换位方案，应用后能一起撤销路线和布阵。新战役打赢第 15 波「内门夺金」后，可自选一枚上阵符文增加 12 点永久威力，领取前能试算第 16 波伤害。旧存档和旧版同局链接按原规则领奖。
- 新战役第 11 波开战前可在「转铸台」免费换一枚同稀有度符文，保留星级和永久威力。「找转铸方案」还会试算转铸后再换位一次的效果。确认前可比较伤害、共鸣与自动升星结果，转铸和换位可以一起撤销。
- 新战役通关后，第 21 波和从第 25 波起的每个天劫区段开战前会停靠营地。可以拿 18 金和两次免费刷新、修复一层护盾，或把离火位挪到另一个格子。营地会实算各选项的下一战伤害；同一波有遗物时先选遗物。对阵表能查看下次换天劫的波次。
- 无尽模式的「敌情 → 六劫路线」可以看完整一轮天劫和本机同起手阵、同难度的最远过关波数。选一个区段可用当前阵容独立试算每一波，点进单场可以换位试打，关掉试阵会回到该区段。
- 打过第 4、8、12、16 波后，每次三选一拿遗物。领取前可比较下一波的伤害、结算金币和额外刷新。若换一个位置能更好地用上选中的遗物，祭坛会画出换位，并试算同一摆法下遗物额外带来的收益。可以只领取，也可以领取并换位，之后还能单独撤销换位。已有对局和旧版同局链接沿用各自的遗物表。
- 「战斗推演」用实际结算规则计算伤害、连击、战斗金币变化和过关奖励（含利息）。拖到新格子或用键盘选中后移动光标，可以先看换位差值。箭头显示触发方向，虚线表示其他作用范围。格号和阵眼名称会一直显示。
- 推演栏的「试阵」可以在副本里换位。伤害不足时，点「找打法」会试遍单步换位，再从较强的摆法里继续试两步。确认应用后才会改变主线阵容，可以用一次撤销恢复。
- 战后点「复盘」，可用 1× 或 2× 回放原阵，也可以逐步查看连锁、敌人生命、毒层和金币。快捷按钮能跳到最大一击、首次轮锁或回合结算。失败结算里也能打开，再用「试这波原阵」换位试打。
- 战斗时可以看扫描格和触发进度。长连锁会合并部分演出，最大一击和击破仍会突出显示。倍速按钮可在 1×、2× 和立即结算间切换；系统设为减少动态效果时会直接结算，完整战斗记录仍可复盘。
- 未击破 Boss 时，先从失败面板对比保盾和扣盾后的重打推演。可以手动试阵，也可以自动查找一两步换位。保存方案后，如果选中的护盾条件下能击破，就可以从结算页直接重打。敌人恢复满血、剧毒清零，已经获得的金币保留。
- 进度保存在浏览器本地。通关或战败后可预览并保存战绩卡，朋友扫图上的二维码就能用同样的开局打同局挑战。
- 首次联网打开后，浏览器会缓存这一版的游戏文件。缓存完成后可断网重开，战役、每日残局、试阵和战绩卡都能继续用。

`src/core/` 是不依赖 DOM 的确定性战斗和经济逻辑；`src/sim/balance.test.ts` 覆盖连锁护栏、毒层、金币、升星等规则。Canvas 和 Web Audio 负责回放，不参与计算。
