# 4×4 词条法阵

在 4×4 棋盘摆放、升级并连锁触发符文。用 20 枚符文搭建连锁、剧毒、点金或暴击阵容。打过 20 波可继续无尽模式。

## 在线试玩

[GitHub Pages 试玩](https://bartcurry.github.io/affix-grid-4x4/)（首次部署成功后可用）。仓库管理员须在 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**。合并到 `main` 或从 `main` 手动运行 **Test and deploy to GitHub Pages**；部署后的真实网址在工作流 `deploy` 任务中显示。PR 只测试和构建，不发布。

## 本地运行

需要 Node.js 20.19+（20.x）或 22.12+ 的当前受支持偶数版本。

```sh
npm ci
npm run dev
npm test
npm run build
npm run preview
```

## 如何玩

- 新局可选借火、养苔、攒钱、落印。选阵时可点符文查看作用和首波推演，然后「开局并打首波」或「先布阵」。一键打过首波后，可从棋盘上方找到本波专属补货。换开局会先确认。
- 棋盘上方的「分享」可生成同局链接。朋友点开就能用同种子、同开局打一局，先比通关波数，再比最高连击。同局挑战单独存档，打完可发回战绩。此前版本的邀请链接会提示失效。
- 布阵时可用「分享 → 接手这一波」发送当前阵容。朋友可以换位、试打、对比伤害和连击，再发回改阵链接。战斗条件和持有符文仍一致时，可把改阵应用到主线，并用撤销恢复。
- 「每日」每天北京时间零点换题。点两枚符文换位再试打，保留流派羁绊并关闭暴击。成绩先比步数，步数相同再比伤害。可补玩近七期、复制当天挑战链接，纪录与战役分开。

- 点击符文查看词条和作用范围；拖动交换法阵、备战区位置，或拖到底部回收区。也可以点选后点击空格移动，或使用详情区的回收按钮。键盘可用方向键、回车和 `Delete` 操作棋盘。
- 购买后先放入四格备战区；同名同星的三个符文自动合成，优先保留法阵上的位置。商店会在买入可升星时提前提示。每波开始自动刷新未锁商品，另有一次免费手动刷新。
- 商店的「升星簿」一起清点棋盘和备战区的同名符文。盯住一枚后，刷到现货会高亮。买一枚就能升星时，可以预先查看保留格、腾出的格和推演伤害，再确认购买。
- 第 2 波商店会给当前开局补一枚搭配符文（占用首个未锁位置）。手动刷新时可指定优先流派：首个未锁位置尽量找同稀有度的对应符文，其他位置仍随机。锁住的商品不会换掉。
- 法阵按从左到右、从上到下激活，连锁立即插入。折射镜触发右边，落铃触发正下方。只在首波，保留开局两枚符文的位置，会额外打出 42 点伤害。
- 从第 4 波起会遇到不同敌人：铁壳卫的前两次受击减伤，漏毒翁怕回合末的毒，石狮的中间两列更好打，回音钟怕连锁，闭门王兼有护甲与连锁弱点。无尽模式轮换这五种敌人。
- 点击顶栏「敌情」打开对阵表，查看各波敌人的生命、招式和布阵提示。可以带当前阵容、金币和遗物试打未来的波次。未来波次的试阵不会改变战役进度。
- 打过第 4、8、12、16 波后，每次三选一拿遗物。领取前可以用当前阵容比较下一波的伤害、结算金币和额外刷新。新局的四个节点现在会出现青玉算盘、化功散等扩展遗物，已有对局和旧版同局链接沿用各自的遗物表。
- 「战斗推演」用实际结算规则计算伤害、连击、战斗金币变化和过关奖励（含利息）。拖到新格子或用键盘选中后移动光标，可以先看换位差值；实线表示连锁目标，虚线表示其他作用范围。
- 推演栏的「试阵」可以在副本里换位。「找一步」会试算现有棋盘与备战区的所有单步换位，摆出伤害最高的一步。确认应用后才会改变主线阵容，可以用撤销恢复。
- 战后点「复盘」，可沿原阵逐步看连锁、敌人生命、毒层和金币，也能直达最大一击和查看伤害排行。失败结算里也能打开，再用「试这波原阵」换位试打。
- 未击破 Boss 时可扣除 1 点护盾，或看模拟广告保留护盾重试。每次重试 Boss 恢复满血、剧毒清零，已经获得的金币保留。广告仅为 1 秒本地模拟，不发网络请求。
- 进度保存在浏览器本地；通关或战败可以导出战绩 PNG。

`src/core/` 是不依赖 DOM 的确定性战斗和经济逻辑；`src/sim/balance.test.ts` 覆盖连锁护栏、毒层、金币、升星等规则。Canvas 和 Web Audio 负责回放，不参与计算。
