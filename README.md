# 4×4 词条法阵

在 4×4 棋盘摆放、升级并连锁触发符文。用 20 枚符文搭建连锁、剧毒、点金或暴击阵容。打过 20 波可继续无尽模式。

## 在线试玩

[GitHub Pages 试玩](https://bartcurry.github.io/affix-grid-4x4/)（首次部署成功后可用）。仓库管理员须在 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**。合并到 `main` 或从 `main` 手动运行 **Test and deploy to GitHub Pages**；部署后的真实网址在工作流 `deploy` 任务中显示。PR 只测试和构建，不发布。

## 本地运行

需要 Node.js 20.19+（20.x）或 22.12+ 的当前受支持偶数版本。

```sh
npm ci
npm run dev
npm test
npm run build
npm run preview
```

## 如何玩

- 借火开局用正常的镜子连锁打首波，不靠隐藏加伤。前三波的提示会先比较免费换位、再看商店；建议不会自动买入或改阵。

- 顶部「每日」每天北京时间零点换一盘，同一天所有人遇到同一题。不算暴击，比较交换步数。近七期可以补玩，也可以从分享链接打开指定日期。纪录与连续解开的期数保存在本机。2026 年 11 月 26 日起轮换新增的五符文残局。
- 局内点「分享」，或结算时点「分享同局挑战」，即可复制包含开局、种子与战绩的邀请链接。朋友打开会从同一套起手阵容开始，先比通关波数，再比最高连击。同局挑战独立存档，布阵时可返回主线。
- 布阵时点「分享 → 这一波」可邀请朋友直接接手当前盘面。点选可看作用范围，换位可以逐步撤销。试打后可对照原阵的伤害和连锁，再分享改好的阵容。试阵与主线各自独立。
- 战后可点「上轮复盘」，失败也能在重试前查看。先看伤害前三名，再按顺序翻连锁、伤害、毒层、金币和增益。复盘保留最近一轮。

- 新局可选借火、养苔、攒钱、落印，分别从连锁、剧毒、金币和增幅起步。四套初始阵容都能直接打过第一波。不同开局的最多通关波次与最高连击分别保存在本机；主动换开局会先确认，不会直接覆盖本局。

- 点击符文查看词条和作用范围；拖动交换法阵、备战区位置，或拖到底部回收区。也可以点选后点击空格移动，或使用详情区的回收按钮。键盘可用方向键、回车和 `Delete` 操作棋盘。
- 点商店价签可以把符文买到四格备战区。同名同星的三个符文会自动合成，优先保留法阵上的位置。商店会提前提示能直接升星的商品。每波开始自动刷新未锁商品，另有一次免费手动刷新。
- 商店点「试摆」可逐格预估购入后的伤害、连锁对象和连带换位，确认后一次完成购买和布阵。能升星时直接预估合成结果，撤销可一并恢复金币、商品和阵容。
- 第 2 波商店会给当前开局补一枚搭配符文（占用首个未锁位置）。手动刷新时可指定优先流派：首个未锁位置尽量找同稀有度的对应符文，其他位置仍随机。锁住的商品不会换掉。
- 法阵按从左到右、从上到下激活，连锁立即插入。折射镜触发右边，落铃触发正下方。
- 点顶部「敌情」可查看后续关卡的生命、敌人规则、悬赏和遗物节点。第 20 波闭门王开场有三层门甲，生命减半后破门，后两排符文和回合末剧毒获得加成。无尽模式轮换五种敌人，闭门王沿用开场护甲与连锁弱点。
- 打过第 4、8、12、16 波后，三选一拿遗物。选择时可对比当前阵容在下一波的伤害和金币。新局从第 8 波后可以遇到「朱漆印谱」，从第 12 波后可以遇到「四行旗」；已有对局和旧同局挑战沿用原来的遗物表。
- 第 5、10、15 波可接悬赏。两条路线会试算当前阵容面对各自敌人的伤害；走加试路线打过可分别多领 6、9、12 金。布阵时随时可改走原路，战败仍按常规结算护盾。
- 「战斗推演」用实际结算规则计算伤害、连击、战斗金币变化和过关奖励（含利息）。拖到新格子或用键盘选中后移动光标，可以先看换位差值；实线表示连锁目标，虚线表示其他作用范围。
- 战斗中会显示扫到哪一格和回放进度。长连锁会自动加快。速度按钮可在 1×、2× 和「即结」之间切换，点「跳过」会立即结算当前一波，完整事件仍可在复盘里查看。
- 未击破 Boss 时可扣除 1 点护盾，或看模拟广告保留护盾重试。每次重试 Boss 恢复满血、剧毒清零，已经获得的金币保留。广告仅为 1 秒本地模拟，不发网络请求。
- 进度保存在浏览器本地；通关或战败可以导出战绩 PNG。

`src/core/` 是不依赖 DOM 的确定性战斗和经济逻辑；`src/sim/balance.test.ts` 覆盖连锁护栏、毒层、金币、升星等规则。Canvas 和 Web Audio 负责回放，不参与计算。

`npm run sim:balance` 每种开局跑 200 局固定种子，报告通关率、卡关波次和符文伤害。模拟使用游戏的商店、布阵、战斗、护盾和悬赏结算，操作由固定策略选出，结果用于比较规则改动。
